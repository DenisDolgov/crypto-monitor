## Соглашения

- Нумерация сквозная с `0001`, файл — `NNNN-kratkoe-nazvanie.md`, имя латиницей, текст по-русски.
- Один ADR — одно решение. Формат: контекст → варианты → решение → последствия.
- Статусы: `Proposed` — решение предложено и ждёт ревью; `Accepted` — смержено и действует; `Superseded by NNNN` — заменено; `Deprecated` — больше не действует.
- ADR попадает в `main` как `Proposed`. Статус меняет человек при мерже PR, вместе с решением по самому PR (мерж — не роль агента).
- Изменить принятое решение можно только новым ADR, который ссылается на предыдущий. Правки «по факту» в старый ADR не вносятся, кроме опечаток.
- Если реализация разошлась с ADR — это дефект реализации либо повод для нового ADR, но не молчаливое исключение. Расхождение фиксируется в ревью.
- Шаблон: [template.md](template.md).

## Что здесь намеренно не решается

Хранилище и история котировок, расписание опроса, алерты, сравнение и ранжирование обменников, веб-интерфейс, юридическая оценка ToS. Это следующие шаги после отчёта о покрытии фидов.
